# Viniemedia

**Sports Videography & Professional Photography**

Viniemedia is an audiovisual portfolio website dedicated to showcasing professional videography and photography, with a particular focus on football, athletes and sporting events.

## About

The project was developed to present Viniemedia's visual identity, showcase its audiovisual work and provide visitors with an easy way to get in touch.

The website combines a minimalist design with a visual-first experience, allowing the projects and media content to take center stage.

## Features

- Responsive layout for desktop, tablet and mobile devices
- Minimalist black and white visual identity
- Portfolio and project gallery
- About section
- Contact section
- Smooth scrolling navigation
- Optimized local images and media assets

## Technologies

- HTML5
- CSS3
- JavaScript
